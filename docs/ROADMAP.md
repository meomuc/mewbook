# MewBook roadmap (public)

The landing page's "Sắp tới Mèo sẽ làm" list is generated from this file by
`landing-mewbook/scripts/update-content.js` on every release build. One item per line:

    - [status] Title | short description | when

`status` is `planned`, `doing` or `done` (a `done` item is not shown). Text is Vietnamese because the page is.
Keep it honest: no dates unless the work is really scheduled (`when` may be a phase such as "Kế hoạch").

- [planned] Gửi sách tới máy đọc sách | Chọn bộ sưu tập, Mèo chép sang thẻ nhớ hoặc máy Boox qua USB | Sắp tới
- [planned] Tìm không dấu & sửa mã hóa cũ | Gõ "nguyen nhat anh" vẫn ra Nguyễn Nhật Ánh; sửa tên sách TCVN3/VNI | Kế hoạch
- [planned] Chuyển đổi định dạng sách | Chuyển giữa các định dạng ebook, chỉ với file không có DRM | Kế hoạch
- [planned] Giao diện tiếng Anh | Chuyển ngôn ngữ ngay trong Cài đặt | Kế hoạch
